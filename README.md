# Descriptive-Statistics-Visualizer

Descriptive Statistics Visualizer: Analyze any numerical dataset using Python to compute mean, median, mode, skewness, and visualize it with a Gaussian distribution overlay!

This repository contains Python scripts to perform statistical analysis and visualization on hospital stay data for acute myocardial infarction (heart attack) patients. The goal is to understand central tendencies and distribution characteristics, including skewness, through statistical metrics and a fitted Gaussian (normal) distribution.

#### Key Features:

1. **Data Cleaning:**
   * **Purpose:** Reads raw Excel data, handles non-numeric values, and removes invalid entries to ensure accurate analysis.
   * **Use Cases:** Prepares real-world, messy data for clean and reliable statistical processing.

2. **Statistical Summary:**
   * **Purpose:** Computes the mean, median, and mode of patient hospital stays.
   * **Use Cases:** Provides an overview of central tendencies for decision-making or further research.

3. **Skewness Detection:**
   * **Purpose:** Measures the skewness of the dataset to determine the asymmetry of the distribution.
   * **Use Cases:** Identifies whether the data leans left, right, or is symmetrical—important in clinical and policy analysis.

4. **Gaussian Fit:**
   * **Purpose:** Fits a normal distribution curve to the dataset for comparative analysis.
   * **Use Cases:** Allows for intuitive comparison between actual data and an ideal distribution.

5. **Histogram Visualization:**
   * **Purpose:** Plots the histogram of the data alongside the fitted Gaussian curve for visual insight.
   * **Use Cases:** Enhances data interpretation by combining statistical and visual perspectives.

6. **Interactive and Interpretable:**
   * **Purpose:** Clearly labeled charts and console outputs make the script beginner-friendly and informative.
   * **Use Cases:** Suitable for teaching, research, or exploratory data analysis.

#### Included Script:

1. **length_of_stay_analysis.py**
   * **Purpose:** A Python script that reads and cleans length-of-stay data, computes key statistical metrics, detects skewness, and visualizes the distribution with a Gaussian fit.
   * **Use Cases:** Best suited for healthcare professionals, analysts, and students working with clinical data.

#### Applications & Use Cases:

1. **Healthcare Analytics:**
   * Enables hospitals and researchers to monitor average patient stay durations and detect anomalies.
   * Helps identify trends that can impact care quality and operational efficiency.

2. **Policy Planning:**
   * Useful for healthcare administrators to plan resource allocation and improve hospital efficiency.
   * Informs staffing, budgeting, and infrastructure decisions based on patient data.

3. **Clinical Research:**
   * Supports medical studies focused on post-AMI (acute myocardial infarction) patient outcomes by understanding hospitalization patterns.

This script provides a streamlined way to interpret healthcare data statistically, helping uncover trends in patient recovery times after acute myocardial infarction.
